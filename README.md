# gamesdb.complewin.ru

Поиск скидок на игры по данным [CheapShark API](https://apidocs.cheapshark.com/): популярные игры,
поиск с тегами и сортировкой, страница игры со сравнением цен по магазинам и аналитика текущих скидок.

Стек: React 19, TypeScript, Vite, Tailwind CSS v4, axios, TanStack Query, Chart.js (`react-chartjs-2`),
React Router.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов и сборка в dist/
npm run lint
```

## Страницы

| Путь | Что там |
| --- | --- |
| `/` | Большой поиск по центру и сетка популярных игр (по числу отзывов в Steam). Клик по поиску или `/` открывает мгновенный поиск поверх страницы. |
| `/search` | Название, теги, магазины, диапазон цены; сортировка по цене, скидке, Metacritic, отзывам Steam и дате выхода; пагинация. |
| `/game/:id` | Все предложения по магазинам со ссылками, лучшая цена, исторический минимум, график цен. |
| `/analytics` | Выборка до 300 текущих скидок: KPI и 8 графиков (магазины, распределения скидок и цен, динамика, год выхода, обычная цена против цены со скидкой). |

## Теги

Жанров в CheapShark нет, поэтому теги виртуальные: каждый превращается в параметры `/deals`
(`onSale`, `AAA`, `steamworks`, `upperPrice`, `metacritic`, `steamRating`). Фильтрует сервер,
поэтому пагинация остаётся честной. Описание тегов лежит в `src/lib/tags.ts`.

## Структура

```
src/api/         клиент axios, типы ответов, нормализация (строки → числа), React Query
src/hooks/       запросы: магазины, популярное, поиск, игра, выборка для аналитики
src/lib/         форматирование, теги, URL ⇄ фильтры, настройка Chart.js
src/components/  шапка, подвал, островки, кнопки-пилюли, карточки игр
src/features/    оверлей поиска, фильтры, графики аналитики
src/pages/       страницы
```
